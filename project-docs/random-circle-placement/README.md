# 충돌 없는 랜덤 원 배치

무작위로 생성한 원들이 서로 겹치지 않도록 중심 거리와 반지름을 비교하는 기하 알고리즘 프로젝트입니다.

## 주요 기능

- GUI에서 생성할 원의 개수를 입력받습니다.
- 각 원의 위치와 크기를 무작위로 생성합니다.
- 두 원의 중심 사이 거리와 반지름의 합을 비교해 충돌 여부를 판정합니다.
- 기존 원과 겹치지 않는 경우에만 화면에 원을 추가합니다.

## 기술

`Python` · `Turtle` · `PySimpleGUI` · `Geometry` · `Random`

## 배운 점

좌표와 거리 공식을 화면 객체의 충돌 판정에 적용하고, 무작위 생성 결과를 조건에 따라 검증하는 방법을 익혔습니다.
