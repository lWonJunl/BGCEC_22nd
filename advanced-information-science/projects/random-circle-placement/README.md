# ⭕ 충돌 없는 랜덤 원 배치

> 무작위로 생성한 원들이 서로 겹치지 않도록 중심 거리와 반지름을 비교하는 기하·GUI 프로젝트입니다.

PySimpleGUI에서 원하는 원의 개수를 입력받고, 조건을 만족하는 위치와 크기를 찾을 때까지 후보를 생성한 뒤 Turtle 화면에 원을 그립니다.

## ✨ 주요 기능

* GUI에서 생성할 원의 개수를 입력받습니다.
* 반지름과 중심 좌표를 지정 범위 안에서 무작위로 생성합니다.
* 기존 원과의 거리를 계산해 충돌 여부를 확인합니다.
* 충돌하지 않는 원만 600×600 경계 안에 그립니다.
* `지우기` 버튼으로 Turtle 화면의 그림을 초기화합니다.

<br>

## 📐 충돌 판정 원리

두 원의 중심을 `(x₁, y₁)`, `(x₂, y₂)`, 반지름을 `r₁`, `r₂`라고 하면 중심 사이 거리는 다음과 같습니다.

```text
distance = √((x₁ - x₂)² + (y₁ - y₂)²)
```

두 원이 겹치지 않으려면 중심 사이 거리가 반지름 합보다 크거나 같아야 합니다.

```text
distance ≥ r₁ + r₂
```

현재 코드는 새 후보를 기존의 모든 원과 비교하고, 한 번이라도 `distance < r₁ + r₂`이면 해당 후보를 버립니다.

<br>

## ⚙️ 생성 범위

| Value | Range |
| :-- | :--: |
| **Canvas boundary** | `-300` ~ `300` |
| **Center x** | `-250` ~ `250` |
| **Center y** | `-250` ~ `250` |
| **Radius** | `10` ~ `50` |

중심 좌표를 경계보다 50만큼 안쪽에서 생성하므로 최대 반지름인 50의 원도 600×600 영역 밖으로 나가지 않습니다.

## 🧩 코드 구조

| Component | Role |
| :-- | :-- |
| PySimpleGUI 이벤트 루프 | 그리기, 지우기와 종료 명령 처리 |
| `draw_circle()` | 중심과 반지름을 Turtle 좌표로 변환해 원 출력 |
| `draw_circles()` | 무작위 후보 생성, 충돌 검사와 개수 관리 |
| `circles` | 이미 배치된 원의 `(x, y, radius)` 정보 저장 |

## ⚠️ 현재 구현의 한계

* 숫자가 아니거나 0 이하인 입력을 별도로 검증하지 않습니다.
* 배치 가능한 수준보다 많은 원을 요청하면 후보 생성이 매우 오래 걸리거나 끝나지 않을 수 있습니다.
* 최대 시도 횟수와 실패 안내가 없습니다.
* 새로 `그리기`를 실행할 때 이전 화면의 원을 충돌 목록에 포함하지 않습니다.
* 함수가 이벤트 루프 안에서 정의되어 있어 재사용과 단위 테스트가 어렵습니다.

<br>
