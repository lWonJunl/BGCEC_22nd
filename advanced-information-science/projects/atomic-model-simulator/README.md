# ⚛️ 원자 모형 시뮬레이터

> 원소를 선택하면 전자 껍질별 배치를 Turtle 애니메이션으로 표현하는 과학·GUI 융합 프로젝트입니다.

PySimpleGUI로 간단한 주기율표 형태의 선택 창을 구성하고, 수소부터 칼슘까지 원소별 전자 수를 여러 궤도에 배치해 움직이는 원자 모형을 구현했습니다.

## ✨ 주요 기능

* 주기율표 형태의 GUI에서 원소 기호를 선택합니다.
* 선택한 원소의 전자 수만큼 Turtle 객체를 생성합니다.
* 원자핵은 빨간색, 전자는 파란색 원으로 표현합니다.
* 삼각함수로 원형 궤도의 좌표를 계산합니다.
* 전자를 여러 반지름의 궤도에 나눠 실시간으로 이동시킵니다.

<br>

## 🧪 지원 원소

| 주기 | 원소 | 전자 배치 범위 |
| :--: | :-- | :-- |
| 1주기 | H, He | 첫 번째 껍질 |
| 2주기 | Li, Be, B, C, N, O, F, Ne | 첫 번째·두 번째 껍질 |
| 3주기 | Na, Mg, Al, Si, P, S, Cl, Ar | 첫 번째~세 번째 껍질 |
| 4주기 | K, Ca | 첫 번째~네 번째 껍질 |

원소별 전자 배치는 H의 `1`부터 Ca의 `2-8-8-2`까지 각 이벤트 분기에 직접 지정되어 있습니다.

<br>

## 💡 애니메이션 원리

반지름이 `r`이고 시간에 따라 증가하는 각도가 `i`일 때 전자의 위치를 다음과 같이 계산합니다.

```text
x = cos(i) × r
y = sin(i) × r
```

같은 궤도에 여러 전자를 표시할 때는 서로 다른 각도 오프셋을 사용하거나 반대 좌표 `(-x, -y)`에 배치합니다. 반복문에서 `i`를 조금씩 증가시키면 전자가 원자핵 주위를 회전하는 것처럼 보입니다.

<br>

## 🧩 코드 구조

| Component | Role |
| :-- | :-- |
| PySimpleGUI `layout` | H부터 Ca까지 원소 선택 버튼 구성 |
| `cycle()` | 원자핵과 필요한 수의 전자 Turtle 생성 |
| `cycle1()` ~ `cycle4()` | 궤도별 전자 좌표 계산 |
| `pd()` | 생성된 전자의 펜을 내려 이동 궤적 표시 |
| 이벤트 분기 | 원소별 전자 수와 궤도 배치 지정 |

<br>

## 🔄 동작 흐름

```text
원소 선택
   ↓
원자핵과 전자 객체 생성
   ↓
원소별 전자 껍질 배치 선택
   ↓

   ↓

```

## ▶️ 실행

```bash
pip install PySimpleGUI
python main.py
```

Turtle과 PySimpleGUI 창을 표시할 수 있는 데스크톱 환경이 필요합니다. GUI에서 원소 기호를 누르면 해당 원자 모형의 애니메이션이 시작됩니다.

<br>

## ⚠️ 현재 구현의 특징과 한계

* 교육용 보어 모형을 단순화해 표현한 것으로 실제 양자역학적 전자 오비탈과는 다릅니다.
* 전자 배치를 원자 번호에서 계산하지 않고 원소별 분기문에 직접 작성했습니다.
* 하나의 원소를 선택하면 무한 애니메이션 루프에 들어가 선택 창으로 돌아오지 않습니다.
* 창 닫기 이벤트를 별도로 종료 처리하지 않아 첫 번째 조건 분기로 들어갈 수 있습니다.
* 유사한 전자 이동 코드가 원소별로 반복되어 유지보수가 어렵습니다.

<br>
