# ▭ 충돌 없는 랜덤 사각형 배치

> 좌표와 너비·높이를 이용해 사각형의 경계 및 상호 충돌을 검사하는 기하·GUI 프로젝트입니다.

PySimpleGUI에서 원하는 사각형 수를 입력받고, 무작위 후보가 600×600 경계 안에 있으면서 기존 사각형과 겹치지 않을 때만 Turtle 화면에 그립니다.

## ✨ 주요 기능

* GUI에서 생성할 사각형의 개수를 입력받습니다.
* 왼쪽 위 좌표와 가로·세로 길이를 무작위로 생성합니다.
* 새 사각형이 600×600 화면 경계를 벗어나는지 확인합니다.
* 기존 사각형과 겹치지 않는 후보만 Turtle 화면에 그립니다.
* `지우기` 버튼으로 현재 그림을 초기화합니다.

## 📐 충돌 판정 원리

축에 평행한 두 사각형은 다음 중 하나를 만족하면 겹치지 않습니다.

```text
첫 번째 사각형이 두 번째 사각형보다 완전히 왼쪽에 있다.
첫 번째 사각형이 두 번째 사각형보다 완전히 오른쪽에 있다.
첫 번째 사각형이 두 번째 사각형보다 완전히 위에 있다.
첫 번째 사각형이 두 번째 사각형보다 완전히 아래에 있다.
```

반대로 네 조건을 모두 만족하지 않으면 두 사각형의 x축과 y축 구간이 동시에 겹치므로 충돌한 것으로 볼 수 있습니다.

현재 `overlap_check()`는 이 원리를 좌우·상하 경계 비교와 포함 관계 조건으로 나눠 구현하고, 화면의 `-300` 및 `300` 경계를 넘는 후보도 충돌로 처리합니다.

<br>

## ⚙️ 생성 범위

| Value | Range |
| :-- | :--: |
| **Canvas boundary** | `-300` ~ `300` |
| **Start x** | `-300` ~ `300` |
| **Start y** | `-300` ~ `300` |
| **Width** | `10` ~ `100` |
| **Height** | `10` ~ `100` |

사각형 후보는 경계 전체에서 만들어지며, `overlap_check()`가 오른쪽과 아래쪽 끝점까지 검사해 화면을 벗어나는 후보를 제거합니다.

<br>

## 🔄 동작 흐름

```text
사각형 개수 입력
       ↓
좌표, 너비와 높이 무작위 생성
       ↓
화면 경계 및 기존 사각형과 충돌 검사
       ↓
충돌 ── Yes ──> 후보 폐기 후 다시 생성
  │
  No
  ↓
Turtle 화면에 그리고 목록에 저장
       ↓
요청한 개수에 도달할 때까지 반복
```

## 🧩 코드 구조

| Component | Role |
| :-- | :-- |
| `overlap_check()` | 화면 경계와 두 사각형의 겹침 여부 판정 |
| PySimpleGUI 이벤트 루프 | 그리기, 지우기와 종료 명령 처리 |
| `draw_square()` | 좌표와 크기를 이용해 Turtle로 사각형 출력 |
| `draw_squares()` | 무작위 후보 생성, 충돌 검사와 개수 관리 |
| `squares` | 배치된 사각형의 `(x, y, width, height)` 정보 저장 |

## ⚠️ 현재 구현의 한계

* 입력값의 자료형과 범위를 별도로 검증하지 않습니다.
* 배치 공간보다 많은 사각형을 요청하면 재시도가 매우 오래 걸리거나 끝나지 않을 수 있습니다.
* 최대 시도 횟수와 실패 안내가 없습니다.
* 충돌 판정이 여러 조건문으로 직접 작성되어 있어 일부 경계·포함 사례를 추가 검증할 필요가 있습니다.
* 새로 `그리기`를 실행할 때 이전 화면의 사각형을 충돌 목록에 포함하지 않습니다.
* 함수가 이벤트 루프 안에 정의되어 있어 재사용과 단위 테스트가 어렵습니다.

<br>
