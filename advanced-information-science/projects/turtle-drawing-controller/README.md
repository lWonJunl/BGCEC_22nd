# 🐢 Turtle 드로잉 컨트롤러

> 키보드와 마우스 이벤트로 Turtle을 움직이며 자유롭게 선을 그리는 인터랙티브 그래픽 실습입니다.

방향키와 `W`, `A`, `S`, `D`에 이동 함수를 연결하고, 마우스로 클릭한 좌표까지 Turtle이 이동하도록 구현했습니다.

## 🎮 조작법

| Input | Action |
| :-- | :-- |
| `↑` 또는 `W` | 위쪽으로 10 이동 |
| `↓` 또는 `S` | 아래쪽으로 10 이동 |
| `←` 또는 `A` | 왼쪽으로 10 이동 |
| `→` 또는 `D` | 오른쪽으로 10 이동 |
| 마우스 클릭 | 클릭한 좌표로 이동 |
| `Esc` | 현재까지 그린 선 지우기 |

영문 키는 코드에 등록된 소문자 `w`, `a`, `s`, `d` 입력을 사용합니다.

<br>

## ⚙️ 구현 방식

이동 함수는 Turtle의 방향을 먼저 설정한 뒤 10만큼 전진합니다.

| Function | Heading | Role |
| :-- | :--: | :-- |
| `turn_right()` | 0° | 오른쪽 이동 |
| `turn_up()` | 90° | 위쪽 이동 |
| `turn_left()` | 180° | 왼쪽 이동 |
| `turn_down()` | 270° | 아래쪽 이동 |
| `blank()` | - | 화면의 그림 지우기 |

`onkeypress()`로 키보드 이벤트를 함수에 연결하고, `onscreenclick(t.goto)`로 마우스 클릭 좌표를 Turtle의 목적지로 전달합니다. 기본적으로 펜이 내려가 있어 이동 경로가 화면에 선으로 남습니다.

<br>

## 🔄 이벤트 연결

```text
사용자 입력
   ├── 방향키 / WASD → 방향 설정 → 10만큼 이동
   ├── 마우스 클릭    → 클릭 좌표로 이동
   └── Esc            → 그린 선 지우기
```

`listen()`을 호출해 Turtle 창이 키보드 입력을 받을 수 있도록 포커스를 설정합니다.

<br>

## ▶️ 실행

```bash
python main.py
```

Python 표준 라이브러리의 Turtle을 사용하므로 별도 패키지는 필요하지 않지만, 그래픽 창을 표시할 수 있는 데스크톱 환경이 필요합니다.

<br>

## ⚠️ 현재 구현의 특징과 한계

* 이동 거리가 10으로 고정되어 있습니다.
* 대문자 `W`, `A`, `S`, `D`는 별도로 등록되어 있지 않습니다.
* 펜 올리기, 색상, 굵기와 이동 거리 변경 기능은 없습니다.
* `Esc`는 선을 지우지만 Turtle의 현재 위치와 방향은 초기화하지 않습니다.
* 명시적인 `turtle.done()` 호출이 없어 실행 환경에 따라 창 유지 방식이 달라질 수 있습니다.
