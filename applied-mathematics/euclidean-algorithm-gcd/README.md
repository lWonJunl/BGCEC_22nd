# 🔢 유클리드 알고리즘 최대공약수 계산기

> 두 양의 정수의 최대공약수(GCD)를 반복적인 나머지 연산으로 구하는 정수론 실습입니다.

유클리드 알고리즘의 수학적 원리를 Python으로 직접 구현하며 나눗셈, 나머지 연산, 조건문과 반복문의 동작을 학습한 기록입니다.

<br>

## 📖 최대공약수

최대공약수(Greatest Common Divisor, GCD)는 두 정수를 모두 나누어떨어지게 하는 양의 정수 중 가장 큰 값입니다.

예를 들어 48과 18의 공약수는 `1, 2, 3, 6`이며, 이 중 가장 큰 수인 6이 최대공약수입니다.

```text
gcd(48, 18) = 6
```

<br>

## 💡 알고리즘 원리

두 양의 정수 `a`, `b`에서 `a ≥ b`일 때 다음 성질이 성립합니다.

```text
gcd(a, b) = gcd(b, a mod b)
```

큰 수를 작은 수로 나눈 나머지로 문제의 크기를 계속 줄여도 두 수의 최대공약수는 변하지 않습니다. 나머지가 0이 되면 그때의 나누는 수가 최대공약수입니다.

### 계산 예시

48과 18의 최대공약수는 다음과 같이 구합니다.

| 단계 | 나눗셈 | 나머지 |
| :--: | :-- | :--: |
| 1 | `48 = 18 × 2 + 12` | 12 |
| 2 | `18 = 12 × 1 + 6` | 6 |
| 3 | `12 = 6 × 2 + 0` | 0 |

마지막으로 0이 아닌 나머지인 6이 최대공약수입니다.

<br>

## 🧩 의사코드

```text
두 양의 정수 a와 b를 입력받는다.

a와 b 중 큰 수를 a로 정렬한다.
나머지가 0이 될 때까지 다음 과정을 반복한다.
    r = a mod b
    a = b
    b = r

a를 최대공약수로 출력한다.
```

<br>

## ⚙️ 구현 방식

[main.py](main.py)는 입력 순서와 관계없이 동작하도록 두 경우를 나눠 처리합니다.

1. 공백으로 구분된 정수 두 개를 입력받습니다.
2. 두 수의 크기를 비교해 먼저 나눌 수를 결정합니다.
3. 두 변수에 번갈아 나머지 연산을 적용합니다.
4. 나머지가 0이 되는 순간 반복문을 종료합니다.
5. 마지막으로 저장된 0이 아닌 나머지를 `gcd`로 출력합니다.

일반적인 유클리드 알고리즘은 두 변수를 한 번에 갱신하지만, 이 구현은 학습 당시 작성한 흐름을 보존하기 위해 두 나머지 연산을 반복문 안에서 번갈아 수행합니다.

## ⚠️ 현재 구현의 입력 조건

- 0보다 큰 정수 두 개를 입력해야 합니다.
- 0을 입력하면 나머지 연산 과정에서 0으로 나누는 오류가 발생할 수 있습니다.
- 음수와 숫자가 아닌 입력은 별도로 처리하지 않습니다.
- 입력값 검증보다 유클리드 알고리즘의 반복 구조를 이해하는 데 초점을 둔 초기 학습 코드입니다.
