### 1기 · 정보과학 심화

* **목표:** Python 문법을 바탕으로 다양한 프로그래밍 환경을 경험하고 실생활 문제를 해결하는 능력을 기르는 과정입니다.
* **내용:** Python 기초, LEGO MINDSTORMS 51515 Python 프로그래밍, VPython과 Turtle 그래픽을 학습했습니다.
* **활동:** 이론을 실습과 연결하고 프로젝트 결과를 구현·발표하며 문제 해결 과정을 익혔습니다.

### 2기 · 응용수학

* **목표:** 정보과학의 기초가 되는 정수론을 바탕으로 수학적 명제를 고민하고 토의·증명하는 논리적 사고 능력을 기르는 과정입니다.
* **내용:** 피타고라스 정리, 페르마의 소정리와 정수의 합동을 살펴보고 여러 증명 방법을 학습했습니다.
* **활동:** 하나의 풀이에 머무르지 않고 학생별로 다양한 증명법을 연구하고 공유했습니다.

### 3기 · AI·프로그래밍 심화

* **목표:** 인공지능 소양과 윤리의식, 활용 능력을 갖추고 인공지능 및 기계학습을 이용해 여러 분야의 문제를 창의적이고 효율적으로 해결하는 능력을 기르는 과정입니다.
* **내용:** 인공지능의 이해, 원리와 활용, 데이터와 기계학습, 인공지능의 사회적 영향을 학습했습니다.
* **수업 방식:** 별도의 코딩 실습 없이 인공지능의 기초부터 최신 기술, 머신러닝·딥러닝 알고리즘과 실생활 활용 사례를 이론 중심으로 학습했습니다.

## 💡 Learning & Project Highlights

### Python Problem Solving

* CodeUp 6001번부터 6098번까지 98개의 기초 문제를 Python으로 해결했습니다.
* 표준 입출력, 자료형, 산술·논리·비트 연산과 흐름 제어를 순서대로 실습했습니다.
* 각 문제의 풀이를 독립된 파일로 보관해 학습 흐름을 확인할 수 있도록 구성했습니다.

### Geometry & Collision Detection

* 두 원의 중심 거리와 반지름의 합을 비교해 충돌 여부를 판정했습니다.
* 사각형의 좌우·상하 경계를 비교해 겹치지 않는 배치 조건을 구현했습니다.
* 무작위로 만든 도형을 조건에 따라 검증한 뒤 Turtle 화면에 표시했습니다.

### Science Visualization

* 선택한 원소의 원자 번호를 바탕으로 전자 껍질별 배치를 계산했습니다.
* 입력 GUI, 계산 로직과 Turtle 애니메이션을 하나의 프로그램으로 연결했습니다.
* 과학 개념을 코드와 시각적 결과물로 표현하는 과정을 경험했습니다.

### Event-Driven Programming

* 방향키와 `W`, `A`, `S`, `D` 입력을 Turtle 이동 함수에 연결했습니다.
* 마우스 클릭 이동과 화면 초기화 기능을 구현하며 키보드·마우스 이벤트를 다뤘습니다.
