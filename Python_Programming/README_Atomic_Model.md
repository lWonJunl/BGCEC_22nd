# 원자 모형 시뮬레이터

선택한 원소의 원자 번호에 맞춰 전자 배치를 계산하고 Turtle 애니메이션으로 원자 모형을 표현하는 GUI 프로젝트입니다.

## 주요 기능

- PySimpleGUI에서 표현할 원소를 선택합니다.
- 원자 번호를 바탕으로 전자 껍질별 배치를 결정합니다.
- Turtle로 원자핵과 전자 궤도를 그립니다.
- 각 궤도 위의 전자를 애니메이션 형태로 표현합니다.

## 기술

`Python` · `Turtle` · `PySimpleGUI` · `Animation`

## 관련 파일

- [Python 소스](<Project03_원자모형 시뮬레이터 프로젝트.py>)

## 배운 점

입력 GUI, 계산 로직과 그래픽 출력을 하나의 프로그램으로 연결하고 과학 개념을 시각적인 소프트웨어로 표현했습니다.
