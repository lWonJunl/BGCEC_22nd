# 충돌 없는 랜덤 사각형 배치

좌표와 너비·높이를 이용해 사각형 사이의 충돌을 검사하고 겹치지 않는 배치를 생성하는 GUI 프로젝트입니다.

## 주요 기능

- GUI에서 생성할 사각형 수를 입력받습니다.
- 각 사각형의 위치와 크기를 무작위로 결정합니다.
- 두 사각형의 좌우·상하 경계를 비교해 겹침 여부를 판정합니다.
- 충돌하지 않는 사각형만 Turtle 화면에 그립니다.

## 기술

`Python` · `Turtle` · `PySimpleGUI` · `Collision Detection` · `Random`

## 관련 파일

- [Python 소스](<Project02_겹치지 않는 랜덤 사각형 생성.py>)

## 배운 점

원과 다른 사각형의 충돌 조건을 직접 설계하면서 도형별 경계 판정 방식의 차이를 이해했습니다.
